# FEAT-038 Manual Sweep

The screens for this arrive with `FEAT-039`; run this sweep together with that one.

## 1. Rename keeps everything

1. Make a profile, add three favourites and watch a film for five minutes.
2. Rename it (Settings → Profile → Manage profiles → Rename).
3. **Expect:** the same three favourites, and the film in Continue watching at five minutes.

## 2. The new name is everywhere at once

1. While that profile is active, rename it.
2. **Expect:** Settings, the chooser and anywhere else the name appears show the new name without
   leaving the screen or restarting.

## 3. What cannot be renamed

1. Try to save an empty name, or one of only spaces. **Expect:** Save is unavailable or the name
   is unchanged.
2. Start a guest session. **Expect:** the guest is not offered for renaming at all.
